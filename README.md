## How to play
- Press **Start Countdown**. You have 60 seconds.
- Click on the boxes to uncover the photos.
- Find the two boxes with the same photo to make a pair.
- If they don't match, they get covered again when you click the next box.
- Match all 8 pairs before the time ends to win.

The reload button on the top left restarts the game with a new board.

## What I practiced

This is my first game on GitHub, so I used it to practice these things:

- Making the countdown with setInterval and stopping it with clearInterval
- Making the board responsive: the boxes change size depending on the screen
- Preloading the photos before the game starts, so they appear instantly.
